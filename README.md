# spam-classifier
spam classifer
📩 Spam SMS Detection using Machine Learning
🚀 Project Overview

This project is a Spam SMS Classifier that predicts whether a message is Spam 🚨 or Not Spam ✅ using Natural Language Processing (NLP) and Machine Learning.

🧠 Key Features
Text preprocessing (cleaning, tokenization, stopwords removal)
Feature extraction using TF-IDF
Model building using Naive Bayes
Data visualization (WordCloud, Bar plots)
High accuracy spam detection
🛠️ Technologies Used
Python 🐍
Pandas & NumPy
Scikit-learn
Matplotlib & Seaborn
WordCloud
📊 Workflow
Data Cleaning
Text Preprocessing
Feature Extraction (TF-IDF)
Model Training (Naive Bayes)
Evaluation (Accuracy, Precision)
